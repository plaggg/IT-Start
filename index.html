O praktykach

Praktyki zawodowe w firmie IT pozwalają uczniowi wykorzystać wiedzę zdobytą w szkole w rzeczywistych sytuacjach.

Podczas praktyk można poznać zasady pracy zespołowej, nauczyć się korzystania z narzędzi programistycznych oraz zdobyć pierwsze doświadczenie zawodowe.

Zadania podczas praktyk

Tworzenie stron

Przygotowywanie stron internetowych z wykorzystaniem HTML i CSS.

Programowanie

Nauka podstaw JavaScript oraz tworzenie prostych funkcji interaktywnych.

Git i GitHub

Zapisywanie zmian w projekcie oraz korzystanie z repozytoriów GitHub.
