# IT Start

## Praktyki zawodowe w branży IT

### Opis projektu

IT Start to prosta strona internetowa poświęcona praktykom zawodowym w branży IT.

Celem projektu jest przedstawienie możliwości zdobywania doświadczenia podczas praktyk w firmach informatycznych oraz pokazanie przykładowych zadań wykonywanych przez praktykanta.

### Zadania podczas praktyk

Na stronie przedstawiono przykładowe zadania, które można wykonywać podczas praktyk:

- tworzenie stron internetowych,
- podstawy programowania,
- korzystanie z HTML i CSS,
- korzystanie z JavaScript,
- praca z Git i GitHub,
- poznawanie środowiska pracy w firmie IT.

### Cele praktyki

Głównymi celami praktyki są:

- zdobycie doświadczenia zawodowego,
- rozwijanie umiejętności programistycznych,
- poznanie pracy w zespole,
- nauka korzystania z narzędzi programistycznych,
- poznanie środowiska pracy w firmie IT.

### Wykorzystane technologie

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

### Struktura projektu

- `index.html` – główny dokument strony internetowej
- `style.css` – style i wygląd strony
- `script.js` – funkcjonalność JavaScript
- `README.md` – opis projektu

### Funkcjonalność

Strona zawiera interaktywny przycisk. Po jego kliknięciu za pomocą JavaScript wyświetlana jest informacja dotycząca celów praktyki.
